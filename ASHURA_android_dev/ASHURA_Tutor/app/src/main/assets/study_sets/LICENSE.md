# Bundled study sets — sources and licence

The Markdown notes in this directory are condensed excerpts of English Wikipedia
articles. Wikipedia text is available under the **Creative Commons
Attribution-ShareAlike 4.0 International licence (CC BY-SA 4.0)**.

- Licence: https://creativecommons.org/licenses/by-sa/4.0/
- Source: https://www.wikipedia.org/
- Attribution: Wikipedia contributors. The exact article and URL for every note
  are recorded in `manifest.json`.
- Retrieved: see `retrieved` in `manifest.json`.

The notes are stored on the device and are never downloaded at runtime. Each
file is verified against the SHA-256 digest in `manifest.json` before it is
added to the learner's library. The app displays the source and licence in the
Library screen.

If you redistribute a modified pack, you must keep the CC BY-SA 4.0 licence and
attribute the source. The application code is licensed separately; this notice
covers only the study-note content in this directory.
