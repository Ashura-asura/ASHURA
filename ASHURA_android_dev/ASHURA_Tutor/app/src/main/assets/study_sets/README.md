# Offline study sets

200 short study notes across 10 subjects, generated by
`tools/fetch_study_sets.py` from open-licensed Wikipedia introductions.

| Subject | Sets |
|---|---|
| Mathematics | 20 |
| General Science | 20 |
| Physics | 20 |
| Chemistry | 20 |
| Python Programming | 20 |
| C Programming | 20 |
| Rust Programming | 20 |
| Electrical Engineering | 20 |
| Basic Electronics and Devices | 20 |
| Advanced Calculus | 20 |

Every set is a plain Markdown file. The app imports a set into its local Room
library, then `QuizBuilder` turns the text into a mixed test: fill-in-the-blank
recall plus definition and explanation questions. The checksum in
`manifest.json` protects against a corrupted or modified asset.

Rebuild with:

```bash
python tools/fetch_study_sets.py
```

The script needs network access only when rebuilding the pack; the shipped app
never downloads study content.
