# Security and privacy baseline

- No account, ads, analytics, or mandatory backend is included.
- Android backup is disabled in this baseline.
- Local study data stays on-device unless a future explicit export/transmission feature is invoked.
- Imported content is untrusted input and cannot change tutor policy or tool permissions.
- Do not render imported HTML as trusted executable content.
- Never run generated code with application process permissions.
- Future network features must disclose transmitted data and preserve offline mode.
- Future model downloads require HTTPS, checksum/signature verification, storage checks, and consent.
- Implement user-facing delete-all-data before public release.
