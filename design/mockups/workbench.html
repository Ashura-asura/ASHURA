Explain how ASHURA routes a request and what the execution trace records.
Ashura20:14:08 Unverified

ASHURA does not run a fixed pipeline for every turn. The NeedField selector scores the available modules, and the controller records the modules that actually ran.

What the trace contains

  1. The routing decision, including selected and skipped modules.
  2. One step per module, with its input, output, duration and operational status.
  3. A separate verification result when an independent check ran.

Data handling

Privacy & storage

What is local, what is not, and what is not implemented.

No telemetry or CDN requests

The UI is served from this process and makes no third-party requests. It does not claim that model traffic is local if the configured endpoint is remote.

Sessions and memory are local files

Stored as plaintext SQLite under data/. ASHURA does not encrypt them at rest. Use OS permissions and disk encryption if that threat matters.

Access logs exclude message content

HTTP logs record request ID, method, path, status, duration and client address. Prompt and answer text are not written to the access log.

Image uploads are temporary

OCR writes the image to a temporary file, runs locally, and removes it in a finally block. Uploads are capped at 12 MB.
